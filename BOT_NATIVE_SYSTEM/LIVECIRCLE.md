# Bot-system LiveCircle and sub-LifeCircles

Scope: technical development and operation of the Character Bot alone. Not LYVRA native life, consciousness, private memory, or identity.

For each facet append evidence-backed entries: `event_id`, `timestamp_utc`, `facet`, `source_ref`, `source_sha`, `cause`, `decision`, `effects`, `validation`, `relation`, `supersedes`, `rollback_ref`.

Relations: KEEP_ACTIVE, KEEP_REACHABLE, ARCHIVE, SUPERSEDE, REJECT_WITH_PROVENANCE, REACTIVATE_WHEN_CAUSALLY_RELEVANT.

A sub-LifeCircle stores facet-local development continuity. Parent Whole-Bot LifeCircle aggregates citations and status, not secrets or private Discord messages. An event is not a verified fact without a source SHA or external receipt. Context release is not forgetting. No automatic identity mutation, never auto-authorize release.

Lifecycle: DISCOVER → AUDIT → PROPOSE → REVIEW → IMPLEMENT (scoped) → TEST → READBACK → RECORD → FREEZE → RECOVERABLE. Blocked steps must remain blocked with explanation.
